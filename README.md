# Sales Forecast Dashboard

## 📌 Overview
This repository contains the **Sales Forecast Dashboard Project**, developed as part of the **Advanced Emerging Technology Course by Edunet Foundation CSR with SAP**.  
The project demonstrates how data analytics, machine learning, and visualization can be applied to predict future sales trends and support business decision-making.

---

## 🎯 Objectives
- Build a **data-driven forecasting model** using historical sales data.
- Apply **data cleaning, feature engineering, and statistical analysis**.
- Design an **interactive dashboard** for business users to visualize KPIs and predictions.
- Showcase integration of **SAP-supported methodologies** in analytics.

---

## 🛠️ Tech Stack
- **Languages:** Python (Pandas, NumPy, Scikit-learn, Statsmodels)
- **Visualization:** Power BI / Matplotlib / Seaborn
- **Dashboard:** Streamlit / Flask
- **Database:** PostgreSQL / CSV datasets
- **Tools:** Jupyter Notebook, GitHub, SAP-supported learning modules

---

## 📊 Key Features
- **Data Cleaning & Preprocessing**: Handling missing values, outliers, and categorical encoding.
- **Exploratory Data Analysis (EDA)**: Trend analysis, seasonality detection, correlation studies.
- **Forecasting Models**: ARIMA, Prophet, and Machine Learning regressors.
- **Interactive Dashboard**: Sales KPIs, regional performance, product category trends, and forecast visualization.
- **Documentation & Presentation**: Includes project report and slides for academic/professional showcase.
